# 프로덕트 종합 평가 (앱 오너 관점)

대상: SQLD 30일 합격 학습 PWA · 목표 사용자: 통근 20~30분/일, SQL 과목 +4~6문제로 합격(60점)

## 종합 판정
학습 루프(문제→SRS→오답→모의고사→통계)와 시험 대비 도구(회차 D-day·기출 유형·실배점 모의고사)가
갖춰진 **완성도 높은 MVP+**. 이번 평가에서 **가장 큰 잠재 리스크였던 "정답 정확성"을 교차검증**해
124문항 중 정답 오류 0건, 해설 문구 1건(q010)만 수정. 목표 정합성(합격 프레이밍)이 약했던 점을 보강.

## 항목별 평가 (5점)

| 영역 | 점수 | 근거 |
|---|---|---|
| 목표 정합성 | 3→**4.5** | (개선 전) 점수만 표시. → **합격 트래커**(남은 점수·필요 문항)로 목표를 직접 조준 |
| 콘텐츠 정확성 | **5** | 전 문항 정답키 독립 교차검증 통과(오류 0). 해설 1건 수정 |
| 콘텐츠 깊이 | **3** | 124문항(기출유형 60). 하루 20 기준 신규는 ~6일분 → 이후 복습·특훈 중심(설계상 전환) |
| 학습 과학 | **4.5** | 확신도 반영 SRS(1·3·7일), 취약 유형·태그 드릴다운, 메타인지 코칭 |
| UX/접근성 | **4.5** | 한 손 UX, 모드별 세션, 확대 허용·포커스·터치영역. 세련된 그린 팔레트 |
| 신뢰성/데이터 | **4** | localStorage + JSON 백업/복원. **설정 자동저장**으로 유실 리스크 제거. iOS 저장소 정책은 잔존 |
| 차별성 | **4.5** | SQL 단계별 실행 시각화 + 확신도 SRS + 실배점 모의고사·추이(기출앱/PDF 대비 우위) |
| 기술 건전성 | **4.5** | 단위 50 + 브라우저 스모크, build/lint 무경고, 순수 함수 로직 |

## 이번 라운드에서 개선한 것
1. **정답 정확성 교차검증**(핵심): 전 문항 독립 재풀이 → 오류 0 확인, q010 해설 '3행→4행' 수정.
2. **합격 트래커**(목표 정합성): 홈·통계에 "합격까지 N점 · 약 M문제 더"를 표시(문항당 2점 기준).
3. **설정 자동저장**: 시험일·목표·비중을 변경 즉시 저장(저장 버튼 혼선/유실 제거).
4. **최근 7일 학습량** 그래프(통계): 습관 가시화로 지속 동기 부여.

## 남은 갭 / 로드맵 (우선순위)
- **[중] 콘텐츠 깊이**: 30일 내내 신규를 원하면 300+ 문항 필요. 현 설계는 4일차 이후 복습/특훈으로
  전환되므로 치명적이진 않으나, 회차별 대비 강화 위해 단계적 확충 권장.
- **[중] 학습 리마인더**: PWA 알림(옵트인)으로 통근 시간대 스트릭 유지 — 백엔드/권한 필요.
- **[하] iOS 스토리지 영속성**: 설치(홈 화면 추가) 유도 배너 + 정기 백업 알림.
- **[하] 로딩 스켈레톤·토스트 표준화**(UX 감사 M5), 설정 슬라이더→스텝퍼(M2).
- **[하] 문항 북마크·개념 검색**: 특정 개념을 온디맨드로 복습.
- **[하] 클라우드 동기화(Supabase)**: 다기기 사용 시. 스키마는 준비됨.
